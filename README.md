# Laboratorio V - APIs REST con Spring Boot

## Descripción

Laboratorio práctico de Programación II sobre el desarrollo de APIs REST utilizando Spring Boot.

El proyecto implementa 10 APIs para administrar diferentes recursos mediante operaciones HTTP:

* Productos
* Estudiantes
* Libros
* Empleados
* Películas
* Cursos
* Vehículos
* Tareas
* Clientes
* Pedidos

Cada API implementa los endpoints GET, GET por ID, POST, PUT, PATCH y DELETE, según lo solicitado en el laboratorio.

## Tecnologías utilizadas

* Java 21
* Spring Boot
* Apache Maven
* Postman
* Git y GitHub

## Ejecución

Para ejecutar el proyecto, utilizar:

```bash
./mvnw spring-boot:run
```

La aplicación se ejecuta localmente en:

`http://localhost:8080`

## Postman

La coleccion de Postman utilizada para probar las APIs se encuentra incluida en el repositorio y está organizada en 10 carpetas, una para cada API.
